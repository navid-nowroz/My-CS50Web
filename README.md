# My CS50Web

This project is a web application developed as part of the CS50 course, focusing on the fundamentals of web development.

## Technologies Used
- HTML
- CSS
- JavaScript
- Flask
- SQLite

## Getting Started
1. Clone the repository: `git clone https://github.com/navid-nowroz/My-CS50Web`
2. Navigate to the project directory: `cd My-CS50Web`
3. Install the required packages: `pip install -r requirements.txt`
4. Run the application: `flask run`

## Project Structure
- `static/` : Contains CSS and JavaScript files.
- `templates/` : Contains HTML files.
- `app.py` : Main application file.
- `requirements.txt` : Lists project dependencies.
